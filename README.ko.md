# dev-stats

[English](./README.md) | [한국어](./README.ko.md)

프로젝트에서 쓴 언어와 도구를 세는 카운터 보드입니다. 항목을 추가하고 숫자를 올리거나 내립니다. Go, Docker, Next.js처럼 알려진 이름에는 로고가 붙습니다.

## 실행

```bash
cp .env.example .env
docker compose up --build
```

`http://localhost:3000`에서 열립니다. DB 마이그레이션은 시작할 때 자동으로 적용됩니다.
