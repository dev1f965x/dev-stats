# dev-stats

[English](./README.md) | [한국어](./README.ko.md)

Counter board for the languages and tools you use across projects. Add an item and count it up or down. Known names like Go, Docker, and Next.js get their logo.

## Run

```bash
cp .env.example .env
docker compose up --build
```

Open `http://localhost:3000`. Migrations are applied on startup.
